# Selection-Construct-Program
Collection of Selection Construct Programs

#### Passed or Failed Grade Program
    Selection #1: Revise your Grade code in Sequence constructs by identifying the remarks 
    whether the average grade is Passed or Failed. If average is greater than or 
    equal to 75 then passed else failed.

#### Positive or Negative Number Program
    Selection #2: Write a code that will input for a number then identify whether the 
    number is positive or negative.

#### Odd or Even Number Program
    Selection #3: Write a code that will input for a number then identify 
    whether odd or even number.

#### Largest Number Program
    Selection #4: Write a code that will input for 2 numbers then identify which 
    of the two is the largest.

#### Smallest Number Program
    Selection #5: Write a code that will input 3 numbers then identify the smallest.

#### General Average Program
    Selection #6: Revise exercise #1 in selection problems by determining the equivalent 
    grade of the computed average: 97-100 = 1.0 | 94-96 = 1.25 | 91-93 = 1.5 | 88-90 = 1.75
    86-88 = 2.0 | 82-84 = 2.25 | 79-81 = 2.5 | 76-78 = 2.75 | 75 = 3.0 | else 5.0

#### Temperature Message Program
    Selection #7: Write a code to read temperature in centigrade and display a suitable 
    message according to the temperature state below: Temp < 0 = "Freezing weather" 
    Temp 0-10 = "Very Cold weather" | Temp 10-20 = "Cold weather" | Temp 20-30 = "Normal Temp"
    Temp 30-40 = "Its Hot" | Temp >= 40 = "Its Very Hot"

#### Total Sales Commission Program
    Selection #8: Revise your Sales problem in Sequence constructs by computing and displaying 
    the sales commission base the given below: Sales <= 15000 = 15% | Sales <= 20000 = 20%
    Sales <= 25000 = 25% | Sales <= 30000 = 30% | Sales > 30000 = 40%

#### Day Format Program
    Selection #9: Write a code to read any day number in integer and display the 
    day name in word format.

#### Vowel or Consonant Letter Program
    Selection #10: Write a code to check whether an alphabet is a vowel or a consonant.
